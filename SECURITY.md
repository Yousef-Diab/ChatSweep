# Security policy

ChatSweep runs with access to your ChatGPT and Claude sessions, so security reports are taken seriously.

Please **don't open a public issue** for a vulnerability. Report it privately through GitHub:
[Report a vulnerability](https://github.com/Yousef-Diab/ChatSweep/security/advisories/new).

Include what you found, how to reproduce it, and which version (see `chrome://extensions`). You'll get a reply as
soon as possible, and a fix will be released before any public disclosure.

Only the latest released version is supported.
